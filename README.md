# 直链文件传输助手 —— 部署指南

适用环境：**宝塔面板 + Apache2.4 + PHP 8.2 (PHP-FPM)**（Linux）

---

## 一、 准备环境
1. 安装宝塔，官网地址：[https://www.bt.cn/](https://www.bt.cn/)
2. 进入宝塔面板官网，选择 **Linux 稳定版** 安装
3. 安装完成后，登录宝塔面板，安装 Apache2.4 和 PHP 8.2
4. 配置 PHP-FPM，设置 `request_terminate_timeout` 为 `3600` 秒（1 小时）

```bash
A. 软件商店 → 已安装 → PHP 8.2.xx → 设置 → FPM配置文件
B. 找到或新增一行（值改为 `3600`）：request_terminate_timeout = 3600
C. 点左下角 「保存」，再去：PHP 8.2.xx → 服务 → 重启
```

| 值 | 含义 |
|---|---|
| `0` | 不限制 |
| `3600` | 最多 1 小时 |
| `100` | 宝塔默认值，**默认值在多线程进行下载会导致文件不完整**  |

5. 配置完成后，部署网站，即可使用直链文件传输助手
